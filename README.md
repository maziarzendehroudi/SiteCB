# Site Web & CMS Headless - Cabinet de Psychanalyse

Dépôt du projet de site internet vitrine et blog pour un cabinet de psychanalyse, doté d'un système de gestion de contenu (CMS) basé sur Git pour une indépendance totale du client.

- **Hébergement actuel de test :** [https://maziarzendehroudi.github.io/SiteCB/](https://maziarzendehroudi.github.io/SiteCB/)
- **Cible de production :** Nouveau nom de domaine (Hébergement OVH)
